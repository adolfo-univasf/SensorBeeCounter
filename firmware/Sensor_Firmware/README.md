# Melissa_Firmware_Caixa
Firmware sensor de contagem de abelhas



## pinos usados ##
* S1 -> GPIO 23
* S2 -> GPIO 2
* S3 -> GPIO 17


### 1.0.1 
* Rotacionar a Tela que estava de cabeça para baixo
* Diminuir o consumo de 60 mA para 18mA adicionado a opção para liga/ desligar o wifi que estava ligado direto com o botão na parte de tras da placa
* diminuiu o tamanho do codigo da main, removendo as linhas de codigo para escrita no display e colocando em funcões em outro arquivo chamado Display
* adicionou o servidor WEB para configarar o id da caixa
